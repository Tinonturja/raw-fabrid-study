# FabriD v3 external geometry and model transfer test

Written after examining the publisher description and ZIP central directory, plus a few polygon-label text entries. No FabriD image has been decoded or model-scored for this follow-up. The dataset and its acquisition groups are separate from RAW-FABRID by publisher description, but physical independence and image provenance have not been established. This is an exploratory cross-dataset transfer and crop-construction experiment.

Use the Mendeley version 3 ZIP with SHA-256 4944cec7f54ce3f9120ed243ea8c33f3ff3a3d4c39556fd06e7cfe3a5b3a05c3. Read images and polygon labels directly from the ZIP without extraction. Use the released test partition only. Pair each image and same-stem label; empty labels represent clean cases. Reject malformed labels or masks, missing pairs, unsupported image geometry, duplicate path names and conflicting exact-image labels. Identify source IDs by the filename before the Roboflow .rf. suffix. When several test images share a source ID, select the lexicographically first image without inspecting its pixels. Report how many are excluded and report source IDs appearing across published splits. This precaution does not establish independence between physical scenes. Use mask polygons converted to native pixels with Pillow; label classes are merged as foreground. Require at least three coordinate pairs and coordinates within [0,1]. Frames smaller than 256 pixels in either dimension are ineligible.

Apply the existing RAW-FABRID seed-13017 models fitted to the 1,000 clean tiles from the saved held-out-Rollo3A fold. Keep model parameters fixed for every FabriD test frame. Convert RGB to grayscale and repeat to three channels as in the RAW-FABRID study. There is no FabriD adaptation, threshold calibration, or target-domain fit.

For each dimension construct a regular 256-pixel step grid and append an edge-aligned window if needed to cover the full frame. On positive frames construct a guided comparison by replacing each grid window containing any marked pixel with a 256-square window centered on the bounding-box midpoint of that window's marked pixels, rounded down and clamped to image bounds. Other windows retain their positions. On clean frames use the same fixed positions. Deduplicate identical positions for inference but keep each policy's original windows for fusion. Both policies use the same number of windows before duplicate coordinates are merged. The guided policy is constructed with the test mask and is an oracle control.

Use 16 × 16 spatial model outputs, nearest-cell expansion and max fusion. Assign uncovered pixels lowest rank. Quantize scores to width 0.001 as in RAW-FABRID. Pool counts and frame scores across the one fixed reference fit, and report per-policy observed-area and whole-frame AP, frame AUROC, native mask coverage, and region overlap up to 0.05 false-positive rate. Use eight-connected components and the same bin-based interpolation defined in the region-analysis protocol. Report both models, all directions, total eligible images, clean and positive counts, unique source IDs, exclusions, and the clean versus positive window counts. Store sufficient score-bin and per-frame summaries for arithmetic checks. These are exploratory benchmark results on polygon-derived masks, not factory performance or a prospective physical-roll test.
