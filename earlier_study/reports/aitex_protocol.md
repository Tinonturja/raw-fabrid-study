# External AITEX acquisition and independent test

Written before opening AITEX images or measuring AITEX model scores. The RAW-FABRID primary spatial result was known. This is a separately fitted test of the crop-placement mechanism, using an artificially constructed guided policy on another dataset. It is not a zero-shot transfer of trained weights or a test of a published AITEX crop policy.

Use the publisher's three original archives. Retain native 4096 × 256 images, convert to grayscale, match defect masks by source stem and union multiple masks. Use foreground ≥128. Report malformed or missing pairings. Deduplicate exact grayscale image content, excluding conflicting clean/defect groups and merging the masks of eligible duplicate positive sources within fabric. Omit cross-fabric duplicate groups. Record all exclusions. Use fabric ID from the published filename. For a complete within-fabric donor cycle, require at least two distinct positive sources and clean frames in each partition.

Use seed 13017. Sort clean filenames per fabric, permute with one seeded generator in sorted fabric order, use the first half for training, divide the remainder into calibration and evaluation halves (odd remainder to evaluation). Use all eligible defective frames for evaluation. Uniformly sample up to 1,000 fixed-grid tiles without replacement from the training images. Refit both RAW-FABRID detector settings using those AITEX normal references. No defect labels enter the model fit.

Use the entire published field of view. The base grid uses sixteen disjoint 256-square windows. For the guided condition, replace each foreground-containing base window with one centered horizontally on the midpoint of the leftmost and rightmost foreground pixels it originally contained. Round down and clamp the left coordinate to the frame bounds. All other windows stay fixed. For three within-fabric donor conditions, reassign whole positive layouts cyclically after a deterministic shuffle seeded with 20261119, always using a different image (reuse donor offsets when a fabric has fewer than four positives). All 16-window clean layouts coincide. The blind overlapping scan has 31 windows at stride 128. Report global-feature and spatial-model frame AUROC, released-style guided minus fixed and guided minus mean donor. Report native pixel AP and region hits for the spatial model with the same clean-calibrated threshold rule and denominators used for RAW-FABRID. An external negative or attenuated result is retained.
