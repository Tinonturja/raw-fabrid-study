# Low-false-positive region analysis and prediction examples

This exploratory follow-up was designed after observing all earlier RAW-FABRID results. It reuses the seed-13017 whole-roll holdout fits and the primary pixel-evaluation cohort of 202 defective and 53 clean frames. It does not constitute an independent confirmatory experiment.

For each held-out roll and each of the existing frozen ResNet-18 PatchCore-style and Swin-T Gaussian configurations, refit the same saved 1,000 reference tiles from the other rolls and replay the 28 released and 28 fixed windows. Use the existing 16-pixel nearest-cell expansion, max fusion, 0.001 score bins, and mask threshold of 128. The released layout assigns uncovered pixels to bin zero, below every observed score. The fixed layout covers every pixel.

Define an 8-connected foreground component in each defective source frame as one region. At each global threshold within a fold and policy, compute the mean fraction of each region whose pixels score at or above threshold. Compute the pixel false-positive rate over every background pixel in the same 255-frame cohort for that fold. Integrate the region-overlap curve from false-positive rate zero to 0.05 using linear interpolation at the boundary and trapezoids, then divide by 0.05. Tied score bins are traversed together. Report all seven within-roll values and their equal-roll mean. This is an operationally motivated secondary metric. It follows the restricted-FPR region-overlap idea but is a study-specific implementation because unobserved released pixels receive the lowest bin. Do not pool scores across refitted folds. Report results regardless of direction.

For visualization, in held-out roll 3A choose the positive frame with the largest number of foreground pixels outside released windows, and the positive frame with the smallest number outside released windows. Break ties alphabetically. Refit both detectors exactly as above and display the original frame, mask and released-window coverage with the two fixed-grid anomaly maps. Each map is min-max scaled within frame for visualization and has its own color scale. Never compare colors as calibrated scores. Record frame names, pixel counts, fit hashes and frame-score checks against the previously saved outputs. The maps are illustrative, selected using the labels, and make no statistical claim.

A separate independent dataset would need source images, per-pixel defect annotations, clean references and usable acquisition groups. LUSITANOv2 has independent production-line images but only bounding boxes, and therefore cannot support a like-for-like pixel or region-overlap test without new annotations.
